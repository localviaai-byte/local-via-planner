# LocalVia

Itinerari curati da chi il posto lo vive davvero.

## Tecnologie

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Supabase

## Sviluppo locale

```sh
# Clona il repository
git clone <YOUR_GIT_URL>

# Entra nella directory del progetto
cd <YOUR_PROJECT_NAME>

# Installa le dipendenze
npm i

# Avvia il server di sviluppo
npm run dev
```
